## Using Examples

Examples demonstrate how templates are applied to real projects. Use them as reference when generating configurations for your own projects.

Each example includes:
- **AGENTS.md** - Root repository guidelines
- **Component AGENTS.md** - Service/component-specific guidelines
- **Additional docs** - Style guides, conventions, etc.

## Contributing Examples

To add a new example:
1. Create a folder with your project name
2. Include a README.md explaining the project context
3. Add the AGENTS.md files that would be used
4. Reference which templates they demonstrate
